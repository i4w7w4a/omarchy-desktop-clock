# Minute Ink

- Версии плагина записывай двумя числами, `MAJOR.MINOR`, например `1.0`, `1.1`, `1.2`. Для очередного обновления увеличивай `MINOR` на один. При смене основной версии начинай с `MAJOR.0`. Используй ту же строку в манифесте, тегах и заметках о выпуске.
- Сохраняй русскую и английскую документацию и каталоги `i18n`. Проверяй манифест через `omarchy plugin validate .` и время и указатель через `python3 -B -m unittest discover -s tests`.
- Публикация в каталоге привязана к точному коммиту. Публикуй проверяемые изменения в отдельной ветке, пока выпуск ещё на согласовании.
