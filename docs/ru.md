# Minute Ink — классические часы на рабочем столе

Крупные часы в классическом стиле для рабочего стола Omarchy. Они видны под верхней панелью поверх обоев, а окна приложений их перекрывают. При наведении цифры слегка увеличиваются и светлеют. Плагин учитывает системную настройку анимаций. В панели доступны поиск шрифта и переключатель «Русский / English».

Проверено на Omarchy 4.5.0, Hyprland 0.56.2, Quickshell 0.3.2-r7 и Qt 6.12. Нужен системный Python 3.11 или новее.

Установка:

```sh
omarchy plugin add https://github.com/i4w7w4a/omarchy-desktop-clock.git --enable
```

Панель выбора шрифта:

```sh
omarchy shell shell summon io.github.i4w7w4a.desktop-clock '{}'
```

Выбери шрифт и нажми «Применить». «Отменить» сбрасывает выбранное, но ещё не сохранённое значение.

Удаление:

```sh
omarchy plugin remove io.github.i4w7w4a.desktop-clock
```

Перед удалением сохрани запись `io.github.i4w7w4a.desktop-clock` из `~/.config/omarchy/shell.json`, если она понадобится при восстановлении. Если вручную добавлял правило порядка слоёв, удали его и выполни `hyprctl reload`. Пример правила, зависимости и проверка описаны в [основном README](../README.md).
